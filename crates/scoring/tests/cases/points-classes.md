# Points-based classes: highest first (S1)

Style classes, Punktespringen, progressive classes and the like are scored on points: the
highest score ranks first, and the faster time decides between equal scores. In the scoring
tables these blocks are marked `prog`. Decided 2026-11-13 (docs/deviations.md S1).
